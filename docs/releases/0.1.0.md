# HOPA 0.1.0 — phone preview

The current HOPA build as a signed HarmonyOS HAP.

## Read this first

HarmonyOS 6 **does not install HAPs from a file download**. The phone only
installs HAPs through AppGallery or `hdc` in Developer mode. This HAP is signed
with the OpenHarmony debug kit and its profile contains the **emulator's UDID**,
so a retail Huawei phone (including the Mate 80) will reject it.

Full, honest instructions:

- [Install on a real phone](https://github.com/michaelatamuk/hopa/blob/main/docs/guides/install-phone.md)
- AppGallery internal testing is the only phone-only path.
- Wireless `hdc` plus a Huawei debug profile is the no-cable developer path.

## What is in this build

- Chat with quiet, bubble-less answers, a typing indicator and a history sheet
  (search, date groups, the active chat pinned).
- Activity: recent actions, runs and batches, Screens, scheduled Plans.
- Capabilities: model and phone-control status, apps, browser, memory, screens,
  models, usage, phone access, MCP, files, source, about.
- Settings behind the gear, with System / Light / Dark appearance.
- Approvals as a bottom sheet owned by the shell.
- Browser with a bottom URL bar.
- Real Bilibili run: opens the page, reads it, answers in Chinese, returns to
  Chat and keeps a link to the page.

## Known limits

- The accessibility extension needs Huawei's AppGallery ACL on a retail phone.
- Untethered app control on the emulator is unavailable; the PC bridge is the
  working path there.
- Speech and system reminders are not available in this SDK/image.
