## What it does

- Harmony visual language: palette, mascot rhythm and bubble, top bar, three
  in-place tabs, chats sheet, Activity, Capabilities.
- Chat with a persisted history, search, date groups, pinned, tombstones,
  ChatSync over the PC bridge (push/merge, pull fallback, draft protection).
- Contracts from `contracts/`: observation producer (refs, redaction, caps,
  hash), schema-validated records, hash-chained run records (last 100).
- Loop with 14 steps, 1 500 ms settle, cancel, duplicate-launch guard, token
  usage and a final text summary.
- Gate: generated policy, payment checkbox, six fixtures executed by name.
- Device paths: PC bridge over adb (primary) and the on-device accessibility
  adapter (fallback) with a disclosure, kill switch, gestures, screenshot
  policy and fail-closed revocation.
- Voice: dictation records 16 kHz mono WAV and sends it to the bridge's
  `/transcribe`; the text lands in the composer, never sent automatically.
- Usage counters, Runs filters/detail/Verify chain, deep link `hopa://ask`,
  PROCESS_TEXT, Ask HOPA shortcut, message Copy/Share.
- Layered adaptive launcher icon: cream background layer, transparent mascot
  foreground inside the safe zone, monochrome layer for themed icons. The brand
  raster `docs/media/mascot-2026.png` is transparent too.
